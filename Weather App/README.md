# Weather App

A simple weather application made with Python and Tkinter. It gets weather information from the OpenWeather API and shows it in a small desktop window.

## Features

- Simple GUI
- Weather information for selected locations
- Temperature in Celsius
- Weather condition and description
- Pressure information
- Uses OpenWeather API

## Requirements

```bash
pip install requests
```

## How to Run

```bash
python project.py
```

Select a location and click the button to get the weather information.

## Files

- `project.py` - main program
- `backgrouud.png` - background image
- `README.md` - project information

## Note

The project needs an OpenWeather API key. Keep the API key private and don't upload it to GitHub.
