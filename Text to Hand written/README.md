# Text to Handwritten

This project was created as a starting point for converting normal text into a handwritten-style image.

At the moment, the main Python file does not contain the actual implementation, so the project is not complete yet.

## Planned Features

- Enter normal text
- Convert the text into handwriting
- Save the result as an image

## Files

- `project.py` - main project file
- `qrcode.png` - image file
- `README.md` - project information
