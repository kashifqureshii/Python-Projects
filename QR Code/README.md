# QR Code Generator

A small Python project that creates a QR code from a URL and saves it as an image.

## Features

- Creates QR codes
- Works with URLs and text
- Saves the QR code as a PNG file

## Requirements

```bash
pip install qrcode[pil]
```

## How to Run

```bash
python project.py
```

The QR code is saved as:

```text
qrcode.png
```

You can change the URL in `project.py` to create a QR code for something else.

## Files

- `project.py` - QR code generator
- `qrcode.png` - generated QR code
- `README.md` - project information
